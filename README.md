# 研迹 · 第二阶段原型

本版本完成了论文项目中的主题图谱、文献 AI 摘要和结构化阅读记录。

## 当前功能

- 类似 Word 开始页的多项目入口
- 开始页新增统一设置中心，集中管理图谱外观和 AI 连接
- 开始页新增账户与同步入口；本地模式无需登录，未来登录仅承载可选同步、备份与账户级 AI
- 创建多个相互独立的论文项目
- 论文项目 → 多个主题 → 多篇文献的图谱式浏览
- 项目内可在“主题图谱 / 研究矩阵”之间切换，两种视图共用同一份数据
- 研究矩阵提供记录视图与文献视图，可按主题、记录类型和未关联章节筛选
- 可直接搜索理论、原文、个人理解、作者、研究问题和论文章节
- 矩阵详情可追溯到来源文献，并从当前素材继续打开 PDF 阅读区
- 项目、主题和文献节点均可拖动，位置自动保存在本机
- 项目名称、图谱简称、说明和标签均可修改
- 项目、主题、文献三类节点均支持添加并显示标签
- 可删除项目、主题或文献；删除前会说明连带删除的内容并再次确认
- 点击文献先从右侧打开 AI 摘要，不立即离开图谱
- 导入 PDF 后只创建文献并显示摘要；点击“打开文献”才进入阅读界面
- 按引言、理论、实验、结果、讨论、结论查看分析
- 每一部分分别显示“说了什么”和“值得借鉴什么”
- 文献记录的左右结构页面
- 打开文献后使用紧凑记录导航、记录区和 PDF 阅读区三栏布局
- 记录区与 PDF 区之间可拖动调整宽度，并记住本机设置
- 理论、概念、方法、证据、局限和个人思考模板
- 新增主题；选择主题后直接导入 PDF 来创建文献节点
- PDF 文件名自动作为文献标题，并识别文件名中的年份
- 新增和整理结构化阅读记录
- 新增记录直接在记录区内展开输入，不使用弹窗
- AI 摘要、记录整理、记录填写和原文解读均使用统一 AI 入口
- AI 设置支持云端兼容 API 或本地模型服务地址；密钥不写入项目数据
- 设置中心新增“云端与服务器”，支持仅本地、托管云端和自建服务器三种部署方向
- 为应用服务器、实时同步、账户认证、云数据库、对象存储与桌面更新分别预留连接窗口
- 云端能力使用稳定适配器端口，未来可更换供应商而无需重写阅读、图谱和矩阵界面
- 所有服务器密码、登录令牌和存储密钥均不写入项目或 Git 仓库
- 阅读状态和新增数据保存在当前电脑的本地工作区
- 为每篇文献导入并在本地保存 PDF
- 内置 PDF 分页阅读、缩放和文件替换
- PDF 采用全部页面连续滚动阅读，触摸板和鼠标滚轮可顺滑浏览
- 自动按需渲染当前附近页面，长文献不会一次性加载全部画布
- 页面离开可视区或缩放时会安全取消旧渲染，不再弹出“Rendering cancelled”错误
- 读取 PDF 内置目录，并支持点击目录顺滑定位到对应页面
- 选中 PDF 原文后自动捕获页码
- 将划线保存为理论、概念、方法、证据、局限或个人思考

AI 内容目前为可交互的示例数据；真实模型的输出结构和分析指令位于 `app/lib/analysis.ts`。

代码按最终打包为本地桌面应用的方向组织：工作区数据、PDF 存储和 AI 连接配置均位于独立模块。第三阶段可将它们替换为桌面文件系统、本地数据库与 macOS 钥匙串，而无需重写项目、图谱、摘要和记录界面。

## 本地运行

需要 Node.js 22.13 或更高版本。

```bash
pnpm install
pnpm dev
```

然后访问 `http://localhost:3000`。
